📌 Gambaran Umum Proyek

E-ARWANA adalah aplikasi tata kelola kearsipan berbasis web yang dikembangkan untuk memudahkan digitalisasi, pendataan, dan pencarian agenda surat masuk, surat keluar, arsip anggaran, secara terstruktur dan efisien.

⚡ Modul & Fitur Utama:
  • Dashboard Analytics: Widget statistik real-time & Grafik rekapitulasi bulanan.
  • Kelola Surat & Anggaran: Manajemen Surat Masuk, Surat Keluar, dan Arsip Anggaran.
  • Quick Menu & Search: Akses cepat navigasi serta pencarian dokumen instan.
  • Manajemen Akses User: Kontrol hak akses multi-user.
🛠️ Arsitektur & Teknologi:
  • Language & Backend: PHP Native, HTML5, CSS3, JavaScript
  • Database: MySQL (Relational Database)
  • UI Framework: Bootstrap 5 & Chart.js Library
  • Deployment: InfinityFree Hosting Server
🌐 Live Demo: Kamu dapat mencoba langsung aplikasinya melalui tautan berikut: E-ARWANA Live Demo
🛡️ Analisis Keamanan Web (OWASP Top 10)
📌 Gambaran Umum Proyek

Evaluasi dan pengujian kerentanan keamanan (Security Assessment) pada sistem informasi pengarsipan berbasis web dengan mengacu pada standar global OWASP Top 10 untuk memastikan kerahasiaan dan integritas data instansi.

🔍 Fokus Pengujian:
  • Broken Authentication: Evaluasi keamanan mekanisme login dan sesi pengguna.
  • Injection Risks: Pengujian validasi input terhadap celah SQL Injection.
  • Access Control: Pemeriksaan celah pembatasan hak akses halaman sistem.
🛠️ Metode & Standar:
  • Standard: OWASP Top 10 (Web Vulnerabilities)
  • Methodology: Black-Box Security Assessment
  • Target Analisis: Sistem Pengarsipan Surat Internal
  • Output: Laporan Celah & Rekomendasi Mitigasi
🔒 Keamanan Sistem: Hasil analisis ini digunakan untuk merumuskan langkah perbaikan kode (*hardening*) guna mengantisipasi potensi ancaman eksploitasi siber.
